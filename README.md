# Dra. Djane Bernardes · Endodontista — Link bio

Mini site (link na bio do Instagram @clinica_dra_djanebernardes).

## Estrutura
```
index.html          → conteúdo e estrutura
css/style.css       → todo o visual (cores e fontes nos tokens do :root)
js/main.js          → faixa animada, nome gigante ajustável, header, animações
img/                → fotos (recorte do hero, consultório, avatar)
```

## Onde editar
- **WhatsApp:** buscar `wa.me/message/LYKWJYTDTHRCL1` no index.html
- **Endereço/mapa:** seção `#consultorio` e `#contato`
- **Cores:** variáveis `--vinho`, `--ouro`, `--noite` em css/style.css
- **Fontes:** Bebas Neue (títulos), Playfair Display itálico (frases), Inter (texto)
